Class: WirehairEncoder

WirehairEncoder()

Encapsulates the Wirehair encoding functionality. Use this class to encode a message into a series of packets.

Constructor

new WirehairEncoder()

Creates an instance of WirehairEncoder. Only usable after calling await initWirehairModule(). Consider using WirehairEncoder.create() instead.
